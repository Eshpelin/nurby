## New issues to create

### Priority 1 — "prove the monitoring loop" bucket

1. **[P1] Dead-man's switch: notify through an out-of-band channel when Nurby stops checking in** (`enhancement`, `roadmap`)
   Nurby can't report its own death; power/internet/host loss is silent and indistinguishable from "all quiet" — fatal for the "monitoring while away" promise. External watchdog (hosted cron/companion) alerts via Telegram/email when heartbeats stop. Eng notes: internal TTL heartbeats already exist (`shared/heartbeat.py`), `/api/health`; notify channels currently run from the same box that dies; companion to #189.

2. **[P1] Camera content health: detect frozen, obscured or tampered views** (`enhancement`, `roadmap`)
   `camera_offline` only catches dead connections; spiderwebs, rain domes, defocus, and turn-to-wall tamper produce normal-looking streams. Frozen-frame detection (frame-hash stability while "online"), periodic VLM "is this view still useful?" check, `camera_degraded` status + rule trigger, surfaced via #194. Eng notes: `services/perception/camera_status_watcher.py`, `services/ingestion/stream.py`, anomaly baseline (`services/perception/baseline.py`).

3. **[P1] Retention for observations, thumbnails and VLM passes** (`enhancement`)
   `services/ingestion/retention.py` prunes recordings/audio/HAR/motion samples but observations, their JPEGs, and `observation_vlm_passes` grow unbounded — long-running installs silently degrade. Define time/size policy + pruning loop + counts in doctor.

4. **[P1] Golden-set evaluation harness for VLM captions and Ask answers on real footage** (`agent-quality`, `enhancement`)
   The 30/30 mocked eval is regression coverage, not accuracy. Build 100–200 labeled real clips (night/IR, rain, deliveries, known/ambiguous faces, no-event cases); score per model and per prompt version; reviewed #195 alerts feed it; gates prompt/model changes and #196/#198 claims. Eng notes: `services/agent/eval/`, `.eval-report.md`.
